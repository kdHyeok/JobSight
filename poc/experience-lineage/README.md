# 경험 병합과 작성 근거 계약 PoC

## 목적

[설계 6.8](../../docs/02-design/features/experience-graph.design.md#68-병합-경로의-정정과-자소서-작성-근거-계약)의 반례를 합성 자료로 검증한다. 서버 기능과 DB 마이그레이션은 미구현이며, 이 코드는 운영 저장 경로에서 호출하지 않는다.

## 진입점과 불변 조건

- `check_contract.py`: 작성 근거 쌍 유지, 병합 경로 전체의 정정 검사, 소유자와 개정 확인, 다른 경험의 사건 연결 거부, 순환 거부.
- 같은 개정 번호라도 경험 id가 다르면 다른 근거다. 현재 사건 소속으로 과거 경험 id를 덮어쓰지 않는다.
- `created_at`의 합성 정수는 UTC 시각의 순서만 나타낸다. 서버는 TIMESTAMPTZ와 실제 소유자 조회를 사용한다.

## 실행과 검증

```bash
python poc/experience-lineage/check_contract.py
```

Python 표준 라이브러리만 사용하며 파일, 네트워크, 개인 자료를 읽거나 쓰지 않는다. 4단계 구현 시 같은 입력과 기대 결과를 REST/MCP 서비스 및 트랜잭션 회귀 테스트로 옮긴다. 이 PoC 통과는 구현이나 운영 검증 완료를 뜻하지 않는다.
